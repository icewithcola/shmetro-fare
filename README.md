# 上海地铁新价格表
来源：上海地铁查询价格网页

# Json 说明
单条记录：

```json
  {
    "from": "高桥西",
    "to": "浦东1号2号航站楼(市域)",
    "fare": "26.00",
    "lineType": "MIXED",
    "minutes": 134,
    "path": "10号线高桥西至天潼路， 换乘12号线至嘉善路， 换乘9号线至中春路， 换乘市域机场线至浦东1号2号航站楼。"
  },
```

| 字段 | 类型 | 含义 |
|---|---|---|
| `from` / `to` | string | 起终点中文站名；市域线同名站带 `(市域)` 后缀 |
| `fare` | string | 总票价（元，两位小数） |
| `lineType` | enum | `URBAN` 纯地铁 / `MIXED` 地铁+市域 / `SUBURBAN` 纯市域线 |
| `minutes` | int | 官方预计时间（分钟），取该 OD 最短路径；不含站外换乘步行 |
| `path` | string\|null | 官方换乘方案文案；镜像行（就是可以反着查）为 `null` |
